Stack

The idea

Launching an outbound campaign is mostly a chain of repeatable work: set up the sending infrastructure, source and qualify leads, write the copy, and wire up the operations around it. Each step is skilled work, but the steps themselves follow patterns. So I built a system in Claude Code that runs that chain.

What it does

The system handles cold email infrastructure setup, lead sourcing, copywriting and campaign operations. What normally takes days of manual work across half a dozen tools happens in minutes, with a human reviewing the output instead of producing it from scratch.

Why I built it

I have run up to six client accounts at once, and the bottleneck was never ideas. It was the setup and operations work that ate the hours. Encoding that work into a system means every new campaign starts from a running position, and my time goes to the parts that actually need judgment: targeting decisions, angle testing and reply handling.

I'll be honest, this is also the direction I think the GTM engineer role is heading. The value is shifting from doing each step by hand to designing the system that does the steps, and knowing enough about every step to catch when the system gets it wrong.
